# Produtora 03 — landing page e Portfólio



## Como executar
Abra o arquivo `index.html` em qualquer navegador.

## Arquivos
- `index.html`: estrutura do site
- `style.css`: estilos responsivos
- `script.js`: menu mobile e carrosséis

As imagens atuais são referências online (Unsplash). Para produção, substitua-as pelas fotos reais do fotógrafo.
